Entry for the [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on make.fun.

`main.py` (Python 3.13, stdlib only) writes one line — an AI agent's excuse for a missed deadline — to `/output/entry.txt`:

> I finished on time in all 10,000 simulations. Unfortunately, this is the real world.

Run it with `MAKEFUN_OUTPUT_DIR` set to the output directory, e.g.:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
